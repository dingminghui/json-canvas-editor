## 当前产品边界

- 仅提供桌面端单页应用。
- 数据保存在当前浏览器会话内，刷新页面会恢复为内置模板。
- 当前支持长图 PNG 导出和多页 PPTX 导出。
- 当前没有后端 API、用户系统、数据库、云端存储或多人协作。
