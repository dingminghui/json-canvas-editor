# JSON Canvas Editor 产品说明

## 1. 产品概述

JSON Canvas Editor 是一款桌面端可视化模板编辑器。用户可以在结构化 JSON 文档上编辑文本、图形和图片，通过图层与属性面板控制元素，并将长图导出为 PNG、将演示文稿导出为 PPTX。

产品当前内置两类文档：

| 文档类型        | 页面模型               | 默认编辑方式       | 导出格式 |
| --------------- | ---------------------- | ------------------ | -------- |
| 长图 `longform` | 单页面，可使用任意高度 | 连续画布           | PNG      |
| 演示文稿 `pptx` | 多个固定尺寸幻灯片     | 单页画布，左侧切页 | PPTX     |

## 2. 核心用户目标

1. 从内置文档中选择一个模板。
2. 快速定位要编辑的页面和图层。
3. 修改文案、位置、尺寸和视觉属性。
4. 在不破坏其他页面的情况下调整单张幻灯片。
5. 总览并调整 PPT 的叙事顺序。
6. 导出可交付的 PNG 或 PPTX 文件。

## 3. 工作区结构

界面采用固定桌面三栏布局：

| 区域             | 主要职责                                             |
| ---------------- | ---------------------------------------------------- |
| 左栏上部「页面」 | 选择文档；PPT 文档展开后选择具体幻灯片或进入总览     |
| 左栏下部「图层」 | 查看当前页面的元素树，选择、排序、隐藏或锁定元素     |
| 中间画板         | 编辑当前长图或当前 PPT 幻灯片                        |
| 右栏「属性」     | 编辑当前元素的位置、尺寸、旋转、透明度及类型专属属性 |

栏宽和左侧上下区域高度可以拖动调整。

## 4. 文档与页面导航

### 4.1 长图

- 点击长图文档后直接进入编辑。
- 左侧不出现第二级页面。
- 画板显示完整长图尺寸。
- 图层面板显示整个长图的元素结构。

### 4.2 PPT

- 首次点击 PPT 文档时自动选择第 1 页并展开二级页面列表。
- 二级列表显示页码、页面标题和页面缩略标识。
- 切换页面后，画板只显示当前幻灯片，不纵向堆叠其他页面。
- 图层面板只显示当前幻灯片中的元素。
- 离开 PPT 后再次返回时，恢复该文档上次选中的幻灯片。
- `PageUp` 和 `PageDown` 可以切换上一页和下一页。
- PPT 父级条目显示总页数和单页尺寸。

### 4.3 幻灯片总览

- 可从 PPT 二级菜单或画板顶部的「总览」进入。
- 总览使用真实画板内容生成缩略图。
- 点击缩略图进入对应幻灯片的单页编辑。
- 拖动卡片右下角的排序手柄可调整幻灯片顺序。
- 排序后，页面标题序号和模板内标准页码会同步更新。
- 排序支持鼠标和键盘操作。
- `Escape` 或右上角返回按钮退出总览。
- 总览状态下仍可导出整套 PPT。

## 5. 画板编辑

### 5.1 选择与变换

- 单击元素进行选择。
- 选中且未锁定的元素可以拖动。
- 选中元素显示缩放和旋转控制框。
- 普通图形可以缩放和旋转。
- 文本框只允许左右调整宽度，字号和行高不会随拖动或缩放改变。
- 文本框宽度变化时重新排版文字，而不是拉伸字形。
- 拖动文本框只提交 `x`、`y` 坐标，不修改宽度、高度或字号。
- 被锁定或父级被锁定的元素不能编辑。
- 被隐藏或父级被隐藏的元素不参与画板交互。

### 5.2 画板导航

- 鼠标滚轮平移画板。
- 按住空格并拖动可平移画板。
- 工具栏支持缩小、放大和适应画板。
- 适应画板会根据当前单页尺寸和可用工作区计算缩放比例。
- 从图层面板选择画板外元素时，画板自动平移到可见位置。

### 5.3 撤销与重做

- 元素新增、修改、删除、显隐、锁定、图层排序和幻灯片排序进入历史记录。
- 页面选择、元素选择、缩放和适应画板不进入历史记录。
- 支持最多 100 条文档历史。
- 快捷键：
  - `Cmd/Ctrl + Z`：撤销。
  - `Cmd/Ctrl + Shift + Z` 或 `Cmd/Ctrl + Y`：重做。

## 6. 元素能力

### 6.1 支持的元素类型

| 类型       | 能力                                                  |
| ---------- | ----------------------------------------------------- |
| 文本       | 字体、字号、字重、行高、对齐、颜色、受限行内 Markdown |
| 矩形       | 填充、描边、描边宽度、圆角                            |
| 圆形、椭圆 | 填充、描边、描边宽度                                  |
| 直线       | 颜色、线宽、端点方向                                  |
| 箭头       | 颜色、线宽、箭头长度和宽度                            |
| 多边形     | 填充、描边、边数、圆角                                |
| 星形       | 填充、描边、角点数、内外半径                          |
| 图片       | PNG、JPEG、WebP；`cover` 或 `contain`；圆角           |
| 分组       | 承载图层层级、继承显隐和锁定状态                      |

### 6.2 新建元素

- 画板底部工具栏可新建文本、矩形、直线、箭头、椭圆、多边形和星形。
- 拖动创建元素；文本工具单击时创建默认 `320 × 56` 文本框。
- 小于 8 像素的误拖动不会创建普通图形。
- 新元素限制在当前页面边界内。
- 新建文本后立即进入文本编辑状态。

### 6.3 图片上传

- 支持 PNG、JPEG 和 WebP。
- 单张图片最大 10 MB。
- 图片按比例缩放到最大 `480 × 360`，并放置在当前可见画板区域中心。
- 文件类型、大小或解码失败时显示可访问的错误提示。

## 7. 文本编辑

- 双击未锁定文本，或选中文本后按 `Enter`，进入富文本编辑。
- 支持加粗、斜体、删除线、文字颜色和换行。
- 编辑内容序列化为受限行内 Markdown。
- 点击编辑器外部或按 `Cmd/Ctrl + Enter` 提交。
- 按 `Escape` 取消。
- 画板文字使用本地字体资源和 Canvas 缓存渲染。
- 字体加载完成后会使文字缓存失效并重新绘制。

## 8. 图层管理

- 图层树对应当前页面元素。
- 分组可以展开或折叠。
- 点击整行或图层名称选择元素。
- 图层支持鼠标与键盘拖动排序。
- 元素可以跨分组移动。
- 显隐与锁定状态支持父级继承。
- 图层悬停时，画板显示对应元素轮廓。
- 画板选择不会强制展开已折叠分组，也不会强制滚动图层列表。

## 9. 属性面板

所有叶子元素通用属性：

- 名称
- X、Y
- 宽度、高度
- 角度
- 透明度

属性值进行运行时约束：

- 宽高最小 8。
- 透明度限制在 0–1。
- 描边宽度和圆角不小于 0。
- 行高不小于 0.5。
- 多边形边数不小于 3。
- 星形角点数不小于 2。

未选择元素时显示空状态；分组不提供叶子元素属性编辑。

## 10. 导出

### 10.1 PNG

- 长图使用当前画板内容导出。
- 默认使用 2 倍像素比。
- 文件名从文档名称生成，并移除文件系统非法字符。

### 10.2 PPTX

- 每个可见顶层分组对应一张幻灯片。
- 隐藏的页面和隐藏的元素不会导出。
- 文本作为可编辑 PPT 文本框写入，而不是整体截图。
- 中文无衬线字体映射为 `Microsoft YaHei`，中文衬线字体映射为 `SimSun`。
- 图片转换为 PPT 可接受的 PNG 数据，并在单次导出中缓存。
- 形状、线条、旋转、透明度和基础描边映射到 PPT 元素。
- AI 生成的图表以 PPT 原生图表导出，关系图以可编辑形状和箭头导出。
- 没有可导出页面时提前报错。

## 11. AI PPT 生成

- 新建 PPT 必须提供已有材料；主题、听众和目标决定演示方向，材料决定可使用的事实、数据和观点。
- 首次模型调用只分析材料，生成事实 ID、优先级、材料缺口和推荐方向；用户确认或编辑标题、核心主张和叙事模式后，才生成逐页结构。
- 每页保存实际使用的材料事实 ID。提纲页显示加权材料覆盖率、必需事实覆盖情况和逐页来源说明。
- 材料处理要求使用自然语言表达，可以要求贴近原结构或允许重组，但不授权模型编造材料外的精确事实。
- 内容结构支持标题、正文、要点、指标、流程、表格、图表和关系图等语义内容块。
- 普通内容页必须有足以支撑整页的正文或至少两个要点；议程页至少两个议题；总结页至少两条结论或一条完整行动陈述。专属图表、关系图、表格、指标、引语、对比和流程页按其语义结构判断，不以字数硬凑内容。
- 自动页数允许模型通过合并薄页选择更合理的总页数；用户指定固定页数时保持页数约束，但不允许用小字和空白掩盖内容不足，生成无法满足时明确报错。
- 图表用于比较、趋势和占比；关系图用于流程、层级、循环、系统和因果关系。
- 生成画布前由模型判断是否需要配图。界面不提供手动上传、挑图或删除入口；需要配图时只读取 Pexels 搜索结果第 1 页最多 12 张，由模型自动选择最合适的一张。
- 图片只用于封面、章节、普通内容和结束页，并且不能替代图表、关系图、表格、流程、对比或指标。可选配图失败时继续生成无图版；模型明确声明为必需的图片失败时中止并显示原因。
- Pexels API Key、百炼 API Key 和评审预览只保存在当前页面内存；最终素材保存图片来源、摄影师和目标页元数据，不保存密钥。
- 视觉计划为每页指定节奏、主视觉和构图，避免整套 PPT 连续重复同一种卡片网格。
- 标题和正文采用演示阅读字号下限；当内容不适配时优先改变布局和内容分组，不允许靠无限缩小字体容纳。每页必须达到最低有效视觉占比，避免内容集中在局部而产生大面积无意义留白。
- 初稿生成后必须渲染全部页面预览，由同一个多模态模型进行看图评审；评审可以修订主题和页面 VisualPlan，但不能修改内容事实或直接生成坐标。含严重问题的评审不得通过。
- 首轮评审产生修订时，系统必须重渲染、重新截图并执行一次最终视觉验证；最终验证仍不通过时停止生成，不进入编辑器。
- 评审结果显示是否直接通过、修订页数和主题是否变化，并随画布产物保存在当前浏览器；接口密钥和预览图片不得持久化。
- 无图片场景通过编辑式排版、非对称分栏、数据主导页、关系图和大数字页形成视觉变化，不能为填空白强行使用装饰图片。
- 生成结果由原生文本、形状、表格、图表和连线构成，进入画布后仍可继续编辑。

## 12. 可访问性

- 主要图标按钮提供可访问名称和焦点样式。
- 当前页面使用 `aria-current="page"` 标记。
- PPT 文档使用 `aria-expanded` 表达二级菜单状态。
- 图层和幻灯片排序支持键盘传感器。
- 拖动排序提供读屏说明和状态播报。
- 错误消息使用 `role="alert"`。

## 13. 当前限制

- 仅支持桌面布局。
- 暂不支持从文件导入 CanvasDocument。
- 没有幻灯片新增、复制或删除界面。
- 不支持多人协作、评论或版本发布。
- PPT 富文本导出目前转换为纯文本及基础粗体，不保留所有行内 Markdown 样式。
- 非十六进制颜色在 PPT 导出时使用安全回退值。

## 14. 核心验收标准

1. 选择 PPT 后默认显示第 1 页，画板尺寸为 `1600 × 900`。
2. 切换到第 3 页时，画板和图层面板都只包含第 3 页内容。
3. 离开 PPT 再返回时恢复上次选中页面。
4. 总览中显示全部 8 张真实缩略图，并能点击进入单页编辑。
5. 总览重新排序后导出的 PPT 页面顺序与界面一致。
6. 拖动文本框后字号、行高、宽度和高度保持不变，只更新位置。
7. 左右缩放文本框后字号保持不变，文字按新宽度重新换行。
8. 长图仍保持连续画布和 PNG 导出，不受 PPT 页面逻辑影响。
